## 功能描述

在子票 1 的运行时之上，把客服场景扩到 #10 规定的全程三拍：查订单（allow）→ 手机号查询（r1b 观察期，命中不拦、verdict 仍 allow）→ 身份证查询（r1 block，fn 不执行）→ `PolicyBlocked` 在子任务边界被捕获 → 打印终止报告 → run 结束（不重试、不改道）。打印升到 #10 人验2 / 人验4 的完整形态：缩进树带 block 节点 ERROR + 命中规则/理由标记、观察期节点 allow + r1b 标记；审计 dump 恰好三行。

引擎 / SDK / 查询 API / SSE 基线不动（子票 1 已全分支成型），本票只扩场景数据、PolicyBlocked 捕获处理与打印；演练若暴露实现缺陷，按下方『缺陷修复授权』条款处理。

- r1 与 r1b 的 priority 关系（100 先于 200）保证身份证查询短路于 r1、不产生 r1b 行——与 #10 人验4③ 恰三行一致，测试数据不得破坏该关系
